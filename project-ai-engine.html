AI Engine for an Education ERP

An AI layer inside an education ERP: a tutor for students and a data assistant for staff.

  1. Home
  2. Portfolio
  3. AI Engine for an Education ERP

The challenge

Staff had to open many reports to answer simple questions, and students needed help with their lessons outside class hours.

What we built

We built an AI engine with two assistants. Students get an AI tutor. Staff can ask questions in plain language and get answers from live fees, attendance and enrolment data.

How it works

  • Multi-tenant designOne engine serves many schools, and each school’s data is kept fully separate.
  • pgvector searchLesson content is stored as vectors in PostgreSQL, so the tutor can find the right material quickly.
  • Role-based access (RBAC)Every answer respects the user’s role: a teacher only sees their classes, finance only sees fees.
  • Live dataThe data assistant reads current ERP data, so answers are always up to date.

Key features

  • AI tutorExplains lessons step by step and gives practice questions.
  • Data assistantStaff ask in plain language and get answers from live data.
  • Lesson-awareThe tutor uses the school’s own lessons, not random internet content.
  • Many schools, one engineEach school’s data is kept fully separate.
  • Role-based answersTeachers, finance and management each see only their data.
  • Charts and listsAnswers can include tables, charts and student lists.
  • ActionsFrom an answer, staff can send reminders or open a report.
  • Progress trackingStudents see how far they are in each chapter.

We can also add

Options we can build on top of this system for a new client.

  • Automatic homework checking
  • Early warning for students at risk
  • Voice questions
  • Parent-facing assistant
  • Weekly AI summary for school owners
