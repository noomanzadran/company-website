Foundation Multisite Website

A static website turned into a custom WordPress theme inside a network of six websites, with forms and email notifications.

  1. Home
  2. Portfolio
  3. Foundation Multisite Website

The challenge

The foundation’s website was static, so every small change needed a developer, and it had to fit into a network of six related websites.

What we built

We turned the design into a custom WordPress theme and added it to a six-site WordPress network, with contact forms and email notifications.

How it works

  • WordPress multisiteSix websites run from one installation, so updates and security are managed in one place.
  • Custom themeThe original design was rebuilt as a WordPress theme, so the team can edit pages themselves.
  • Forms and notificationsVisitor messages go straight to the right person by email.

Key features

  • Custom themeThe original design rebuilt as a WordPress theme.
  • Six-site networkAll sites run from one installation with shared updates.
  • Easy editingThe team edits pages, news and stories without a developer.
  • Contact formsMessages go straight to the right person by email.
  • Mobile-friendlyEvery page works well on phones.
  • Central securityUpdates and backups are managed in one place.
  • Fast pagesOptimised images and caching for quick loading.
  • Search-friendlyClean structure that helps Google find the pages.
